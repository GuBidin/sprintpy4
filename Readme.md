## 💡 Sobre o Projeto

O **Modo IA – Câmera JOVI** é uma proposta de solução tecnológica que busca transformar a câmera dos smartphones JOVI em uma ferramenta inteligente de apoio aos estudos.

O projeto tem como público-alvo estudantes, especialmente aqueles que possuem uma rotina acadêmica intensa e precisam de praticidade para organizar conteúdos, registrar informações e otimizar o tempo de estudo.

A proposta é integrar recursos de tecnologia e inteligência artificial à experiência da câmera, permitindo que o smartphone seja utilizado também como uma ferramenta de produtividade e aprendizagem.

## 🎯 Objetivo

Desenvolver uma solução que facilite a organização de materiais acadêmicos por meio de registros fotográficos, oferecendo recursos para armazenamento, gerenciamento e consulta de informações.

Além de beneficiar os estudantes, a proposta busca agregar valor aos smartphones JOVI, criando uma experiência diferenciada e aumentando a atratividade dos dispositivos para o público estudantil.

## ⚙️ Organização do Projeto

O projeto foi desenvolvido em Python e está organizado nos seguintes módulos:

| Arquivo | Descrição |
|---|---|
| `main.py` | Arquivo principal responsável pela inicialização e execução do sistema. |
| `interface.py` | Responsável pela interface de interação com o usuário. |
| `armazenamento.py` | Módulo responsável pelas operações de armazenamento de dados. |
| `servicosAPI.py` | Módulo destinado à integração e utilização de serviços de API. |
| `documentacao_sprint4.pdf` | Documentação complementar da Sprint 4. |
| `Readme.md` | Documentação geral do projeto e instruções de execução. |

## 🐍 Tecnologias Utilizadas

- **Python:** linguagem principal utilizada no desenvolvimento.
- **APIs:** integração com serviços externos.
- **JSON:** estrutura de dados para armazenamento, quando aplicável.

## 🚀 Benefícios da Solução

**Para os estudantes:**
- Organização dos materiais acadêmicos.
- Facilidade de acesso às informações.
- Otimização da rotina de estudos.
- Utilização da tecnologia como apoio à aprendizagem.

**Para a JOVI:**
- Diferenciação no mercado de smartphones.
- Agregação de valor aos dispositivos.
- Aproximação com o público universitário.
- Oportunidade de inovação por meio da inteligência artificial.

## ▶️ Como Executar

1. Certifique-se de possuir o Python instalado.
2. Clone ou baixe o repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute o seguinte comando no terminal:

```bash
python main.py
```

5. Siga as instruções apresentadas na interface do sistema.
